# 爆款标题公式与 A/B 评分标准（title-formulas.md）

标题决定公众号打开率的 80%。好的标题必须**引发好奇、承诺价值、圈定人群或制造反差**，严禁使用干瘪平淡的说明性文字。

---

## 一、 七大爆款标题公式

### 1. 认知颠覆公式（否定常识 + 意外事实）
- **核心逻辑**：打破读者心中的固有认知，迫使点击探究。
- **句式模板**：大家都在【做A】，为什么真正的高手都在【做B】？/ 别再【做A】了，【新事实】才是真相。
- **示例**：*《大家都在疯狂写 Prompt，真正懂 AI 的人早就在做 Agent 了》*

### 2. 量化反差公式（具体数字/时间 + 夸张反差）
- **核心逻辑**：数字越精准，可信度与冲击力越强。
- **句式模板**：从【数字A】到【数字B】，我们花了【时间】：背后的【核心逻辑】。
- **示例**：*《从 0 到 10,000 Star 只用了 45 天：复盘一个开源项目的破圈全过程》*

### 3. 人群召唤公式（特定身份 + 极痛困境 + 解决方案）
- **核心逻辑**：精准击中特定垂直受众，让读者觉得“这就是写给我的”。
- **句式模板**：写给【目标人群】：如果你还在为【痛点】发愁，这【数量】个工具能帮大忙。
- **示例**：*《写给不会写代码的运营同学：如何用现成 Agent 搭建自动化工作台》*

### 4. 亲历复盘公式（第一人称 + 真实动作 + 情绪/代价）
- **核心逻辑**：真实感最强，读者最爱看作者亲身踩坑的内幕。
- **句式模板**：我花了【时间/代价】尝试【某事】，总结出这【数量】个血泪教训。
- **示例**：*《我把团队的公众号运营交给了自动化 AI，这是运行一个月的真实结果》*

### 5. 趋势预警公式（时代/技术变化 + 潜在危机）
- **核心逻辑**：制造紧迫感，激发不落人后的避险心理。
- **句式模板**：当【新事物】开始普及，这【几类人】可能要最先面对现实了。
- **示例**：*《当本地开发工具全面接入自动化，未来的程序员到底靠什么立足？》*

### 6. 实操避坑公式（踩坑场景 + 解决指南）
- **句式模板**：为什么你的【产品/文章】总是【失败】？原因可能藏在这【细节】里。
- **示例**：*《为什么你的 AI 写的文章总有一股“机器味”？教你三招彻底洗掉》*

### 7. 终极盘点公式（高信息密度承诺）
- **句式模板**：深度长文：一文讲透【复杂主题】的前世今生与未来走向。
- **示例**：*《万字长文：解构 2026 年最值得关注的 AI Agent 架构演进》*

## 二、 标题 A/B 测试评分指标（满分 10 分）

在 `publish-info.md` 中为生成的备选标题进行评分推荐：
- **吸引力（3分）**：第一眼是否有点击欲望？
- **相关性（3分）**：是否切中正文核心事实，避免纯标题党带来的取关反噬？
- **受众精准度（2分）**：目标读者看到后是否能产生“与我相关”的代入感？
- **阅读节奏（2分）**：中英排版是否顺畅，读起来是否琅琅上口？
