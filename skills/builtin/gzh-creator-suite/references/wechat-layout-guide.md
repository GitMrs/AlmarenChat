# 微信公众号排版样式与视觉规范指南

> 绝大部分公众号文章读不下去，不是因为内容差，而是因为排版灾难：段落密密麻麻像水泥墙、配色五颜六色像打翻调色盘、字号过大刺眼或过小费神。
> 本指南提炼三大顶级科技/内容品牌（Claude、OpenAI、Google）的排版设计语言，输出可直接复制粘贴进入微信官方编辑器的富文本排版标准。

---

## 一、微信移动端基础排版通用铁律

无论采用哪种具体视觉风格，以下参数是微信移动端排版的“基准线”：

1. **容器宽度基准**：微信公众号移动端正文黄金阅读宽度为 **`max-width: 677px`**（或 100% 居中无水平滚动条）。
2. **正文字号**：严格保持在 **`15px` 至 `16px`**（默认推荐 `15px`，最耐读、不占屏）。
3. **行间距（Line-height）**：设置为 **`1.8` 至 `1.95`**。过小（如 1.5）会导致多行文字粘在一起，过大（>2.1）会导致视线跳行。
4. **段落间距（Paragraph Margin）**：段与段之间推荐底部留白 **`1.2em` 至 `1.6em`**，杜绝两段紧挨。
5. **对齐方式**：采用 **两端对齐（`text-align: justify;`）**，中文标点与英文混排时两侧整齐切齐。
6. **全篇色卡严控**：一篇文章内，**核心主色不得超过 1 个，强调点缀色不得超过 1 个**！禁止花花绿绿的大红大绿混用。
7. **微信原生复制规范**：直接复制进微信公众号编辑器的 HTML **必须全部使用行内样式（Inline Styles）**；微信编辑器会自动过滤外部 CSS 文件、`<style>` 标签与自定义脚本。

## 二、三大风格系统与色盘规范

### 1. Claude 风格（知性人文、思想随笔、深度研报首选）
- **视觉心智**：温润羊皮纸质感、书卷沉静气息、适度克制的留白、长篇阅读极度舒适。
- **色彩规范**：
  - 正文文本：`#171717` 或 `#2b2b2b`（微暖深炭黑）
  - 次要说明：`#6f6a62`（铅笔灰）
  - 核心点缀色：`#a16207`（暖琥珀棕）或 `#c96442`（陶土赭石）
  - 引用与卡片底色：`#fffaf0`（暖杏仁白）配合浅金左边框 `3px solid #d8b37c`
- **典型组件**：顶部小写英文 Kicker 引导条、圆角 `8px` 浅暖色引用块、精致虚线分割线。

### 2. OpenAI 风格（技术教程、产品发布、架构剖析、开发者实战首选）
- **视觉心智**：极简白底、高反差纯黑、极客工具感、如文档般清晰利落。
- **色彩规范**：
  - 正文文本：`#111111`（纯正深黑）
  - 次要辅助：`#5f6368`
  - 标题强调：二级标题下方带 `2px solid #111111` 实线装饰下划线
  - 代码与调用块：浅灰底色 `#f6f8fa`，配浅边框 `1px solid #e5e7eb`，等宽字体 `Menlo, Monaco, Consolas`
- **典型组件**：深色/浅灰代码高亮框、紧凑干净的参数对照表、黑底白字微型徽章（Badge）。

### 3. Google 风格（数据对比、产品横评、教育科普、行业榜单首选）
- **视觉心智**：明快轻盈、模块化卡片、四色微点缀、信息分块极具现代感。
- **色彩规范**：
  - 正文文本：`#202124`
  - 品牌点缀：科技蓝 `#1a73e8`、活力绿 `#188038`、阳光黄 `#fbbc04`
  - 卡片容器：淡蓝底色 `#e8f0fe`，圆角 `8px`，顶部配 3px 彩色功能指示条
- **典型组件**：多列横向对比卡片、带打分星星的指标对照栏、醒目的重点提示弹盒。

## 三、文章核心模块行内样式（可直接复用 HTML 片段）

### 1. 二级标题（H2）黄金样式
```html
<h2 style="font-size: 18px; font-weight: 700; color: #171717; margin-top: 36px; margin-bottom: 16px; padding-bottom: 8px; border-bottom: 2px solid #171717; letter-spacing: 0.5px;">
  一、核心架构与演进脉络
</h2>
```

### 2. 重点金句 / 关键论断强调块
```html
<blockquote style="margin: 24px 0; padding: 14px 18px; background-color: #fffaf0; border-left: 4px solid #c96442; border-radius: 0 8px 8px 0; font-size: 15px; line-height: 1.8; color: #333333;">
  <strong>核心判断：</strong>工具的进化不是为了替人偷懒，而是把最优秀的实践沉淀为流水线，让个体能够直接调用工业级的生产力。
</blockquote>
```

### 3. 避坑警告 / 边界提示盒
```html
<div style="margin: 24px 0; padding: 16px 20px; background-color: #fef2f2; border: 1px solid #fecaca; border-radius: 8px; font-size: 14px; line-height: 1.7; color: #991b1b;">
  <strong>⚠️ 实操注意与风险边界：</strong>未经实机压测前，切勿将并发数调整超过 10，否则将触发目标 API 的硬性限流熔断。
</div>
```

### 4. 正文段落（默认呼吸感）
```html
<p style="font-size: 15px; line-height: 1.9; color: #2b2b2b; margin-bottom: 20px; text-align: justify; letter-spacing: 0.3px;">
  这一步的核心在于把复杂的规则转化为机器可执行的确定性约束。当每一个环节都有明确的边界时，系统的可靠性才会呈指数级上升。
</p>
```
