# CSV 业务数据分析

读取当前空间中的销售 CSV，计算可核验的业务指标，并同时生成 Markdown 报告和可直接预览的静态 HTML 报告。

## 输入

CSV 必须包含以下列：

- `date`：`YYYY-MM-DD` 格式的业务日期
- `product`：非空产品名称
- `amount`：可解析为数字的销售额

## 执行要求

1. 只能调用清单中声明的 `analyze` 入口。
2. 输入和输出必须是当前空间内的相对路径。
3. 不得联网，不得读取环境变量，不得安装依赖。
4. 报告必须包含总销售额、按产品汇总、最近两个月环比以及异常记录。
5. 完成后必须同时提交 Markdown 和 HTML 两个产物。

## 验收

- 两个输出文件均存在且非空。
- Markdown 包含“总销售额”“产品汇总”“月度变化”“异常记录”。
- HTML 是无需外部资源即可打开的完整文档。
- 输入中的空产品、非法日期、非数字金额和非正金额均能被记录为异常。
