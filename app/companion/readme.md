 ### 一、 官方网站最具特色的 5 大设计亮点

  #### 1. 浮层气泡对话（Floating Comic Bubbles）
  •
  不是传统单调的聊天列表：原站没有把聊天放在左右分栏的传统输入框里
  ，而是像漫画或游戏 AVG
  一样，文字气泡直接飘在角色身旁（带有可爱的小尾巴 ny-
  bubble__tail，半透明暖粉/奶油色阴影）。
  •
  随着角色说话，气泡在头部附近冒出，阅读完毕后自然往上滑出淡化，互
  动感和代入感极强。

  #### 2. 底部悬浮胶囊坞（Floating Dockbar）
  • 底部是一个居中的悬浮 Dockbar（胶囊输入栏），支持：
      • 极简输入框（语音/打字）；
      • Quick
      Reactions（快捷互动浮块）：在输入框上方横向滑动的一组快捷小
      卡片（如“拍拍头”、“今天好累”、“讲个故事”），一键触发角色动作
      与专属回复；
      • 展开小抽屉（音乐、换装、小工具）。

  #### 3. 顶部轻量 HUD 状态胶囊（Top HUD Chips）

  • 顶部悬浮着一组精致的毛玻璃微胶囊：
      • 角色切换头像（Faceswap）：小巧可爱的 Nari / Yume
      头像，点击即无缝切人；
      • 好感度/陪伴进度条（Bond Level）：如 Lv.3 心动 +
      细细的经验槽；
      • 打卡天数（Streak Chip）：记录连续陪伴天数。


  #### 4. 独特的温暖动漫手绘风（Warm & Tactile Aesthetic）

  • 原站使用了带有“新野兽派/复古日漫”质感的温暖配色：
      • 不用死板的纯黑纯白，而是温润的深巧克力色线条（--ny-line:
      #4a2e1f）配合高饱和暖米色/粉奶油色底（--ny-bg: #fff4e0）；
      • 带有 2~3px 的微粗边框与实体硬投影（box-shadow: 0 4px 0
      var(--ny-line)），按下去有真实的玩具按压回弹感（Press
      feedback）。

  #### 5. 虚拟手机小抽屉（The Toy Phone Drawer）

  •
  点击功能按钮时，从底部滑出一个可爱的复古玩具手机拟物弹窗（带着听
  筒、小圆摄像头和屏幕边框）。
  •
  里面可以放置：小游戏、音乐播放器、相册记录、以及动作表情调试！把
  复杂的工具性配置巧妙包装成了角色的“私人物品”。

  我们可以分阶段逐步吸纳这些精髓，让我们的 /companion 完成蜕变：

  #### 建议第一步：全屏舞台 + 身旁悬浮对话气泡（轻量、立竿见影）

  1. 纯净全屏舞台：
      • 默认隐藏繁琐的右侧表格，让角色位于屏幕中央；
      •
      现有的控制面板收入右上角的悬浮胶囊中（正如刚才做的收起功能，
      或作为“开发者/调试工具”）。
  2. 在角色身旁引入聊天气泡：
      •
      用户发送一句话，角色身侧弹出一个温暖的对话气泡，文字打字机展
      开。
  3. 底部极简输入胶囊：
      • 底部常驻一个像 iOS 悬浮胶囊一样的灵动输入条（输入文字 /
      发送）。

  #### 建议第二步：接入我们现有的 LLM（打通大模型情绪）

  • 我们项目中已经封装了完整的 OpenAI SDK / ModelClient
  与多种大模型。
  • 让大模型在回复时附带一个情绪标签（如 [happy], [shy],
  [wink]），前端收到回复瞬间自动触发对应动作和表情：
      • 用户说：“夸夸我呗” -> 角色触发 俏皮眨眼 + 星星眼
      并输出语音/文字；
      • 用户说：“好难过啊” -> 角色触发 亲昵靠近 + 安静听你说。

  ### 🔍 深入拆解：人家网站（NariYume App）究竟做了什么？

  #### 1. 界面重心不是“模型播放器”，而是“全屏沉浸伴侣空间”

  •
  现状对比：我们当前页面右侧/下方的面板更像“开发者调试台”（排满了
  76 个动作列表、表情按钮和进度条）。
  • 官方做法：默认进入时没有任何多余按钮干扰视线，立绘占满屏幕（PC
  居中，手机大特写），眼神跟随你的光标移动。所有功能全部收纳在底部
  的**“灵动胶囊底栏”（Dockbar）**中。
  #### 2. 灵动胶囊底栏 (.ny-dockbar)
  在立绘正下方悬浮着一个高质感圆角胶囊工具条（Nari
  为温柔粉色系，Yume 为清新薄荷绿系）：

  • 💬
  即时倾诉框（Composer）：像微信/短信一样的极简输入栏，输入一句话
  直接和她对话。
  • 📞 语音电话模式（CallOverlay）：点击电话图标进入 📞 Call ·
  01:23 实时通话界面，带实时语音、麦克风收音和字幕打字动画。
  • 🎛 互动应用抽屉（Apps /
  Games）：点击抽屉展开更多功能（把我们做好的动作表情库、镜头调节
  面板收纳在这里）。
  #### 3. 浮层式对话气泡 (.ny-chatlayer)
  •
  消息直接悬浮在立绘下半部分（带柔和渐变与小尾巴的可爱对话气泡）。
  • 伴侣回复时：角色会自然张嘴说话（驱动 ParamMouthOpenY
  口型），并根据回复的情感自动切换开心的笑脸或害羞动作。
  #### 4. 专属陪伴小功能（极为亮眼）
  • 📖 StudyWithMe（专注自习室 /
  番茄钟伴读）：她安安静静在旁边陪你学习/工作，动作平缓自然，到时
  间轻声提醒。
  • 🌙 BedtimeStories（睡前故事 / 晚安陪伴）：夜间模式读治愈读物。
  • 🐢 小游戏（Games）：而 AlmarenChat
  后端刚好已经有现成的海龟汤探案 API (/api/turtle-
  soup)，可以直接让她陪你玩海龟汤！
