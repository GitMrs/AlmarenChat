# 宏观公布结果与市场验证

事件雷达现在将三份信息分开保存与展示：FairEconomy 日历的预期和前值、补充源的实际公布结果、OKX 的事件窗口价格统计。真实值不会从行情反推；自动补采也不等于人工核验完整复盘。

## 覆盖范围

白名单覆盖 Flash 制造业/服务业 PMI、ISM PMI、CPI/PPI/PCE（核心与整体、月率与年率分开）、月度 ADP、非农、失业率、初请、零售、GDP、密歇根消费者信心及利率决议的数值结果。只有来源系列名称、美国、日期和来源钟点均匹配且唯一时才填值。CPI/PPI/PCE 的部分公开响应没有月率/年率标签；这些分项的规则已接入，但在来源口径不完整时保留“等待来源核验”，不保证全部自动取得实际值。没有映射规则的项目展示“暂未接入结果源”，不做模糊匹配。

讲话、会议纪要、政策声明、发布会保留“文字事件，待来源核验”。本次没有接入自动原文摘要。分组事件仍按每个阶段自己的时间与来源展示结果，不将决议数值套给讲话。

## 数据源与口径

- 原日历仍来自 FairEconomy/ForexFactory 周导出，该导出不含实际值。
- 补充来源为 Nasdaq 公开经济日历接口 `https://api.nasdaq.com/api/calendar/economicevents`，属于聚合源，不标成统计机构直连。
- 该接口的 ISO `date` 查询参数存在美东日期边界行为：实测查询目标美东日需传次一 UTC 日期。响应的 `gmt` 列实际是固定 UTC−5（EST，不随夏令时变化），例如冬令时美国 Flash PMI 显示 09:45、夏令时 FOMC 显示 13:00。匹配时使用固定 UTC−5，不能使用会切换夏令时的纽约钟点。转换仅封装在适配器中，原事件的 UTC 时间不变。已用不同日期的公开响应核对；若上游修改此行为，应修改适配器并重新核验。来源时刻不匹配或重复行时不填写。
- 单次请求复用同一美东日内的数据，成功响应缓存 60 秒；不引入 API 密钥。
- 来源的预期、前值与原日历不一致时保留双方信息，前值差异不自动宣称为官方修正；预期冲突时不自动给 BTC 方向。
- 发布前允许更新日历预期；发布后冻结日历基准及其记录时间。首次记录晚于公布时只算数值对照，不冒充事前预期差。

## 采集与状态

生产环境复用鹰眼 30 秒调度，独立于空间、持仓和计划。未到公布时间不取结果。缺值或失败时：公布后首小时约每分钟重试，之后六小时内每五分钟，其后每小时，自动补采最多 72 小时。可在事件卡手动补采历史结果；手动请求同一任务至少间隔 30 秒。

已取得的值在 72 小时内每小时复查；变化时保留此前数值和采集时间。失败、缺值、晚到的旧请求不会覆盖已取得的有效结果；事件改期清除旧时间的结果。结果写入与原日历、行情、复盘共用进程内串行合并队列。沿用现有 JSON 文件存储，不增加数据库迁移；不应以多个写进程同时修改同一文件。

页面分别显示待公布、等待公布值、采集失败、超出自动补采窗口和已采集状态，并提供检查时间、重试时间、来源及数值更新记录。手动“同步日历”也尝试一批到期公布值，两个结果分开返回。

## 计算与解读

严格比较同口径数值，支持负数、零、千分位、K/M/B/T 和百分比。百分数做差显示“个百分点”，PMI 使用指数点。区间利率不冒充单点做差。

通胀超预期/低于预期只给政策预期路径下的参考偏向，明确标为系统规则。增长、就业和利率不按数值大小机械映射 BTC 方向，允许“影响分歧”与“待确认”。实际结果同步进入 AI 雷达上下文、特战队研判入口和现有鹰眼事后通知；行情窗口仍独立展示，不声明单一事件因果。
