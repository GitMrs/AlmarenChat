# 陪伴页原型与验证

访问 `/companion`。页面暂未添加到导航、聊天页或个人中心入口。

Yume 的环境微风仅作用于头发、头饰、袖口、蝴蝶结、配饰和裙摆，不驱动身体、手臂或腿部姿态；身体动作仍由原有动作参数带动物理联动。

全部名称、原始资源 ID 和动作时长见 [完整清单](./CATALOG.md)。

## 当前能力

- 本地加载 Nari（197 个网格）和 Yume（650 个网格），使用 WebGL2 绘制，支持网格变形、遮罩、混合形态和绘制顺序。
- 控制面板顶部可切换角色；展示全部本地动作与表情。Nari 提供 38 个动作和 9 个表情，Yume 提供 38 个专属动作、1 个共用 Nari 动作和 6 个表情，均可复位为自然表情。动作按日常、心情、互动、亲昵、原始编号等分组，在列表内滚动选择，悬停可查看原始动作 ID。
- 切换角色时取消上一角色的资源请求、释放图形资源，并重置动作、表情和播放设置，避免角色状态串用。
- 支持播放、暂停、重播、循环、进度拖动、速度、缩放、自动眨眼、手动眨眼以及鼠标/触屏视线跟随（Look-at Tracking）。
- 切换动作、切换表情、重播与复位时，通过参数快照与 Smoothstep S 型曲线平滑融合过渡（Motion Blending），结合动画元数据中的 FadeInTime 淡入时长，彻底消除姿态切换时的跳变闪烁。
- 视线跟随支持指针平滑指数阻尼逼近与 3 秒静止平滑回正，层叠驱动眼球、头部（倾角与歪头）及躯干角度，并在控制面板中提供独立开关。
- Yume 加载原有物理配置，以固定 30Hz 粒子链将动作输入与视线转动联动到头部、身体、头发等变形参数；暂停保持输出，拖动与复位时重新稳定物理状态。
- 浏览器标签页隐藏时停止更新模型，页面退出时取消加载和动画，并释放图形资源。
- 桌面左右布局，手机上下布局；加载错误和图形上下文中断时可重新加载。

## 文件

- `app/companion/page.tsx`：独立页面及禁止搜索引擎索引的 metadata。
- `components/companion/CompanionPreview.tsx`：预览界面和控件。
- `components/companion/CompanionStage.tsx`：资源加载、渲染循环和生命周期。
- `lib/companion/motion.ts`：Version 3 动作曲线采样及播放时间计算。
- `lib/companion/physics.ts`：物理输入归一化、粒子链模拟及输出参数联动。
- `lib/companion/catalog.ts`：各角色的模型路径、贴图、姿态、动作和表情配置。
- `lib/companion/vendor/`：隔离的原站渲染核心子集及来源说明。
- `public/companion/models/nari/`：从本地导出目录复制的 54 个资源文件，包括全部 38 个动作。
- `public/companion/models/yume/`：从 Yume 本地导出目录复制的 54 个资源文件，包括 4 张贴图、姿态配置和 39 个动作资源（含一个共用动作，使用其原有 Nari 路径）。

页面的模型、贴图和动作请求均为本站静态资源路径，不需要原站账户、解密密钥或在线模型服务。

## 验证

`node --test lib/companion/motion.test.mjs` 验证四类动作曲线、循环边界、真实动作数值、动作与表情目录完整覆盖，以及两个角色的资源路径、表情参数和所有动作在多个采样帧下实际网格顶点的有限值和变化。

`yarn tsc --noEmit --incremental false` 检查 TypeScript。

浏览器验证覆盖两个角色的实际模型显示、Yume 的 12 个动作和 6 个表情（包括比心和打招呼）、来回切换、加载中快速切换、表情复位，以及 1280px 桌面和 390px 手机布局。先前 Nari 的暂停、循环、复位和进度检查也已通过。

## 当前范围

此版本用于确认自定义 Koro 模型在项目内可显示和播放动作，已接入动作过渡平滑融合与指针视线跟随。聊天与语音口型联动尚未接入。Yume 已接入物理模拟，Nari 暂直接播放原有动作曲线。软件 WebGL 测试环境的帧率不代表实际设备硬件加速下的性能。
