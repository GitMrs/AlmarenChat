# 对话提示词边界

`conversation-grounding.mjs` 维护两种共享文本：

- `RESPONSE_GROUNDING_GUIDANCE`：角色自然表达、按需追问、事实与推断、记忆来源、操作结果、媒体感知和格式边界。小伴、单个 Agent、空间成员发言及 Worker 任务执行共用，不指定统一性格或固定回复长度。
- `CONVERSATION_GROUNDING_GUIDANCE`：包含上述边界，并补充聊天专用的当前时间与对话状态规则。用于小伴和单个 Agent 的网页、QQ 聊天，也覆盖浏览器本地模型路径。

角色配置仍负责身份、性格与语气。空间和任务模式仍由各自运行时决定权限、交接、提交及输出协议；通用边界不能代替这些协议。新增规则优先修改共享文本，避免在角色提示词中重复叠加相反要求。

这组约束借鉴参考项目 `dafeiyu-astrbot` 的自然回应和证据边界，仅调整本项目提示词，不引入其专属称呼、亲密关系、表情频率或输出正则过滤。提示词只能引导模型，实际权限与完成校验仍依赖程序执行。
