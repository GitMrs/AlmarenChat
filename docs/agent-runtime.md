# Agent Runtime

本文档记录空间任务运行时的当前协议、安全边界和重要变更。代码与测试是行为的最终依据；本文档用于说明设计原因、部署影响和排障入口。

## 当前流程

1. Coordinator 根据已授权目标和空间成员派发一个或多个步骤。
2. Advisor 产出分析或建议；获得工作区写入授权时也可以生成文件。
3. Executor 在当前任务的暂存工作区内读取和修改文件。
4. Executor 必须调用 `submit_task_result` 提交结构化完成结果，普通文本不能结束步骤。
5. 平台生成并校验 `ArtifactManifest`。校验失败时，错误返回同一个 Worker 工具循环继续修复，不立即创建新的 attempt。
6. 平台校验通过后，Coordinator 根据任务验收标准、Worker 摘要和产物证据进行验收。
7. Coordinator 接受后，暂存文件才会应用到空间正式工作区；要求返工时继承已有暂存成果进入下一 attempt。

## 完成协议

Executor 的完成工具参数保持精简：

```json
{
  "summary": "已完成工作与验收证据的简短摘要",
  "remainingIssues": []
}
```

约束：

- `summary` 不能为空。
- `remainingIssues` 非空时不能完成，Worker 必须继续处理。
- 完成提交会触发平台产物校验和 Skill 产物类型校验。
- 同一响应同时包含文件操作和完成提交时，运行时先执行文件操作，最后执行提交。
- 不使用正则或额外模型请求判断 Worker 是否已经完成。
- Coordinator 验收仍然保留，平台校验不能替代业务验收。

## 工作区与工具

每个任务在空间目录下使用独立的 attempt 暂存区。工具只能处理经过标准化的空间相对路径，拒绝绝对路径、路径穿越和符号链接越界。

当前主要工具：

- `list_files`：列出工作区文件。
- `read_file`：分页读取 UTF-8 文本文件。
- `write_file`：创建文件或在明确授权时完整覆盖文件。
- `patch_file`：精确替换单个文件内容。
- `patch_files`：批量精确替换；先在内存中验证全部修改，失败时不提交修改，写入异常时尝试恢复原内容。
- `check_files`：检查文件存在性、空文件、JSON 和 HTML 本地资源引用。
- `run_check`：执行平台白名单内的 JavaScript、TypeScript 或 HTML 内联脚本语法检查。

`run_check` 不允许任意命令、构建、安装依赖或启动服务。HTML 检查只把内联 JavaScript 交给 Node 解析，不执行页面代码；外部脚本和非 JavaScript 数据脚本不会执行。

静态 HTML 预览和公开分享使用同一套 sandbox 权限：允许脚本、表单、原生模态框和下载；不允许同源身份、弹窗或顶层导航。资源加载继续受各自 CSP 的同空间路径限制。

## 模型请求

- 单次模型请求使用总墙钟超时，覆盖请求建立、完整流式响应读取和一次瞬时故障重试。
- Provider 重试不会获得一份新的完整超时预算。
- 任务与运行级模型请求预算仍由数据库原子计数控制。
- 遥测失败不能反向导致已成功的模型请求失败。
- 文件写入或补丁成功后，后续模型请求只保留工具名称、路径和省略字符数；工具执行仍使用原始参数，失败调用保留完整参数供模型纠错。

模型请求完成后写入 `MODEL_REQUEST_COMPLETED` 事件。事件只保存统计信息，不保存提示词、API Key 或工具参数内容。

主要字段：

| 字段 | 含义 |
| --- | --- |
| `scope` | `task` 表示 Worker 请求，`run` 表示 Coordinator 等运行级请求 |
| `taskId` / `agentId` / `attempt` | 关联步骤、成员和执行轮次 |
| `iteration` | 当前工具循环轮次 |
| `durationMs` | 包含完整流式消费的总耗时 |
| `requestChars` | 请求消息和工具定义的字符量，仅保存数字 |
| `contentChars` / `reasoningContentChars` | 输出正文和推理内容字符量，仅保存数字 |
| `toolCallCount` | 响应中的工具调用数量 |
| `retryCount` | Provider 瞬时故障重试次数 |
| `providerUsage` | Provider 返回时保存 token 用量数字 |

任务详情会聚合显示模型耗时、重试和 token。Provider 未返回 token usage 时显示输入字符量；只有部分请求返回 token 时标记为“已上报 Token”。历史任务不会补算这些指标。

## Pi Space Skill 脚本审批

Pi 空间只有在用户明确选择的 Space Skill 包含已由管理员批准的 Python 脚本时，才会获得 `run_skill` 工具。普通文件读取、写入、修改、检查、联网搜索和 `read_skill_file` 不进入这套审批流程。

每次调用 `run_skill` 都执行以下流程：

1. 平台校验当前 Skill、版本摘要、脚本白名单和输入文件相对路径。
2. Pi 暂停当前工具调用，页面展示 Skill 名称、脚本路径和输入文件范围。
3. 用户确认后，平台再次校验 Skill 版本与实际文件路径，再通过强制沙箱执行脚本；用户拒绝时将拒绝结果返回 Pi。
4. 用户停止 Pi 或等待确认超过 5 分钟时，平台自动拒绝并清理待审批记录。

当前 Space Skill 脚本固定使用 `python3`，只能只读访问当前 Pi 工作区中的 `.md`、`.txt` 和 `.json` 输入文件，单次最多 10 个；脚本不能联网、安装依赖、修改工作区或运行自定义命令。Linux 必须安装 Bubblewrap，缺少强制沙箱时拒绝执行，不降级为宿主机直接运行。

待审批状态与活动 Pi Session 一样保存在 Next.js 单进程内存中，适用于当前单实例部署。多实例部署需要迁移到数据库或共享存储；当前页面刷新后不能恢复审批弹框，未处理的请求会在超时后自动拒绝。

## 部署注意

- 更新代码后需要重启 Worker，新的完成协议、校验和遥测才会生效。
- 前端和 Worker 必须部署同一版本，避免页面已支持新事件但 Worker 尚未写入事件。
- 模型遥测本身不需要数据库迁移，继续复用 `AgentRunEvent.payload`。
- 接力协作需要应用 `20260907160000_add_space_relays` migration，并同步重启前端与 Worker。
- 正在执行的旧任务不应跨版本热切换，建议等待完成或停止后再重启 Worker。

### 2026-09-07 - Pi 会话上下文压缩

- Pi 的完整 JSONL 会话继续保留在空间私有运行时目录，用于恢复与审计。
- 每次请求模型前，只对已经成功且超过 12,000 字符的 `write_file`、`patch_file` 和 `patch_files` 参数生成精简副本；保留工具名称、调用 ID、文件路径和省略字符数。
- 失败、尚未完成和小型文件修改保留原始参数，确保 Pi 仍可继续纠错。
- Pi 最终答复按模型增量实时发送；模型转为工具调用时清除临时正文，过程说明仍单独进入执行记录。
- 多成员 `@` 回复时，每个 Pi 角色只代表自己回答并禁用执行工具；后续成员使用本轮发送前的共同上下文，不携带前面成员刚生成的回答。

### 2026-09-07 - Pi 协调者轻量成员协作

- 项目执行空间默认由可见的空间协调者接话；普通问答和文件项目由协调者直接使用 Pi 完成，不生成 Native 任务方案。
- 用户明确要求大家回应、讨论、评审、决策或接力时，协调者通过结构化 `coordinate_members` 工具选择真实空间成员、模式与轮数，不代替成员编造回答。
- 平台复用逐成员流式回复队列，每位成员的结果分别写入聊天记录，最后由协调者汇总；协作轮次禁用文件、联网和 Skill 工具。
- 单次轻量协作最多 6 位普通成员且固定为 1 轮；协调者随后总结并说明缺口，不自动追加成员轮次。用户需要继续时以新的自然语言消息发起，沿用已有会话上下文。

### 2026-09-07 - 接力协作基础协议

- 新增独立于任务和讨论的持久化接力状态机，支持自动执行、逐轮确认、取消、最大轮次和 Worker 重启恢复。
- Native 空间协调者可在普通对话中调用 `start_relay`，公开展示参与成员、顺序和完成条件，不再要求用户配置独立接力弹框。
- 普通协作统一使用 `submit_relay_turn` 提交文字成果并直接进入聊天记录；平台确定性轮转，协调者只在开场、异常调整和最终验收时出现。
- 成员判断完成后先持久化成果，再由协调者通过结构化验收决定结束或追加一轮；总结失败可从持久化阶段恢复，不重复成员成果。
- `EACH_TURN` 模式下，协调者要求追加一轮时先等待用户选择“继续一轮”或“结束接力”，确认前不调用下一位成员；`AUTO` 模式在轮次上限内直接继续。
- 五子棋仅作为双人规则适配器，负责坐标和胜负校验，并生成 `state.json` 与只读棋盘预览。
- 接力运行时不开放联网、终端或 Space Skill 脚本，并与任务、讨论互斥运行。
