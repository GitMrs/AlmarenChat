# 微信公众号专用工作室：信息收集与需求梳理

日期：2026-11-09。状态：调研记录与建议，尚未实施，不代表所有功能已确认。

本文保留调研当时的代码现状；后续实施及 2026-11-10 的验收结果见 [开发计划](./WECHAT_WORKSPACE_DEVELOPMENT_PLAN.md)。

## 范围与信息来源

只针对微信公众号专用工作室。复用现有空间的成员、聊天、任务、文件、审批与自动化基础，不调整普通空间、合约、Bilibili、Studio 或单 Agent。

依据当前仓库代码与本次访问的微信官方文档。产品建议、代码现状、官方限制分别记录；没有执行真实公众号账号验证，也没有做竞品实测。

官方文档：

- [新增草稿](https://developers.weixin.qq.com/doc/service/api/draftbox/draftmanage/api_draft_add.html)：本次读取页面标注更新于 2026-11-02。
- [发布草稿](https://developers.weixin.qq.com/doc/service/api/public/api_freepublish_submit.html)：本次读取页面标注更新于 2026-10-20。
- 数据统计、群发、留言、第三方授权等暂未完成逐接口核对，本文不承诺这些能力对所有账号可用。

## 核心使用流程

账号定位 → 选题与资料 → 讨论和明确本篇需求 → 写作与修改 → 配图排版 → 发布前检查 → 微信草稿／手动复制 → 发布结果 → 复盘。

流程应允许跳步：可以只讨论、只改一段、只排版，也可以导入已有文章。不能强制每篇重新做定位、生成整套文件或启动多成员协作。

## 已核实的官方约束及代码差异

1. 新增草稿文档规定标题总长度不超过 32 个字。当前 `wechat-official-account.mjs`、`wechat-article-snapshot.mjs` 使用 `slice(0, 64)`；现有处理与文档不一致，后续应明确校验和提示，不能静默裁剪。具体 Unicode 计数和边界以官方接口实测为准。
2. 正文文档要求少于 2 万字符且小于 1MB。当前草稿快照限制的是 Markdown 文件大小，不能代替最终 HTML 的字符数和大小检查。
3. 正文图片 URL 需由微信上传图文图片接口产生，封面需要永久素材 ID。当前连接器已有对应上传能力，应复用并展示缺失素材，而不是允许任意外链后承诺发布成功。
4. 官方草稿接口支持 `cover_info` 的 2.35:1 与 1:1 裁剪信息。当前模板用中央 42.6% 安全区提示生成封面；这只是创作建议，不能替代实际裁剪预览和提交参数。
5. 发布接口返回成功仅代表任务提交成功，最终可能失败。当前发布状态查询流程应保留；不应在提交时展示为已发布。
6. 官方发布文档要求核对实际账号接口权限，并列出需要到公众平台手动操作的错误。当前错误码 48001 的提示偏向“已认证服务号”，应按实际账号权限描述，不能仅凭账号名称推断可用性。
7. 当前连接器调用 `freepublish/submit`，不应因此承诺已向粉丝群发通知。发布、群发、定时群发需分别核对接口、配额和账号权限。
8. 官方页面说明新增草稿、发布支持第三方平台代商家调用，但属于不同授权集。集中授权是后续选项，不在本次直接替换 AppID/AppSecret 配置。

## 专用界面建议（待确认）

以“文章”为主要工作对象，保留自然对话作为讨论和发起任务入口。

- 对话：讨论、选题、反馈、发起或继续任务。
- 文章：选定选题后的正文、需求、大纲、发布资料与修改记录。
- 素材：参考文章、来源、封面和正文图片。
- 发布：检查、草稿、审批、最终链接和错误恢复。
- 账号设置：定位、风格、连接、能力可用情况；纯写作不强制连接微信账号。

选题池第一阶段可作为文章页内区域，避免先建设复杂内容管理系统。阅读数据看板、多人实时编辑、营销自动化、任意 CLI 执行均不作为第一阶段前提。
