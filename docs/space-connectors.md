# 空间连接器

空间连接器负责把空间内已经完成、已经审批的成果交给外部平台。它不参与内容生成，也不扩大 Agent 或 Skill 的工具权限。

当前边界：

- 凭据归属于单个空间，使用 `SPACE_CONNECTOR_SECRET` 通过 AES-256-GCM 加密。
- API 和前端只返回公开配置、状态和错误摘要，不返回凭据或访问令牌。
- 微信公众号适配器支持令牌刷新、图片素材上传、草稿创建、发布提交和发布状态查询。
- 保存凭据后需要执行一次只读连接校验；校验会强制重新获取 Access Token，以提前发现无效凭据和服务器 IP 白名单问题。
- 连接校验由 Worker 异步执行并写入动作审计，但属于低风险动作，不要求用户再次审批；只有状态为 `READY` 的连接器才能提交草稿审批。
- 连接器代码不会被普通对话或任务工具直接调用。
- `WECHAT_CREATE_DRAFT` 和 `WECHAT_PUBLISH` 都定义为高风险动作，必须通过 `SpaceActionRequest` 明确审批。
- 公众号文章预览可以选择空间图片作为封面并提交草稿动作审批。
- 公众号自动化可以选择“定稿后准备微信草稿”和排版主题；该策略会冻结在自动化执行对应的定稿请求中，后续修改规则不会改变已经等待审批的成果。
- 自动化执行完成后先请求用户确认定稿。定稿通过后，系统只从同一 `SpaceWork` 选择唯一 Markdown 正文和唯一封面，冻结 HTML、文件信息及 SHA-256 哈希，再生成独立的草稿审批。
- 正文或封面缺失、存在歧义、连接器未就绪时，成果仍会正常定稿，并在聊天中提示用户整理文件后手动创建草稿。
- 审批后的草稿创建与发布由 Worker 异步执行；创建草稿成功后只生成新的正式发布审批，不会连带发布。
- 动作请求冻结正文并记录素材哈希；审批后素材变化会使执行失败，避免发布未经确认的内容。
- Worker 在外部请求过程中异常退出时将动作标为结果未知，不自动重放可能已经生效的请求。
- 正式发布提交成功后进入 `WAITING_PROVIDER`，Worker 以 30 秒至 5 分钟的退避间隔查询微信状态，最多查询 24 次。
- 只有微信返回发布成功时才将动作标记完成，并保存文章 ID、发布 ID 与最终文章 URL。
- 已持久化发布 ID 的失败动作可以由用户重新查询状态；该恢复动作不会再次提交发布。
- 公众号创作室提供独立发布记录，最近 100 条草稿与正式发布动作可查看审批状态、草稿 ID、发布 ID、文章 ID、最终链接、时间和失败原因。

部署前需要提供稳定的独立密钥：

```env
SPACE_CONNECTOR_SECRET="至少 32 位的随机字符串"
```

更换或丢失该密钥后，已有连接器密文无法恢复，需要重新配置对应平台凭据。
