# AI 模型与运行方式

本文档说明 Agent 私聊和网页小伴的模型选择。代码和测试是行为的最终依据。

## 两层配置

个人中心的“AI 模型设置”保存线上模型和本地 Ollama 的配置。个人中心选择的方式只是默认值；进入 Agent 或小伴聊天后，输入框上方可以单独切换“线上 / 本地”，不会覆盖个人中心保存的配置。

本地配置只保存在当前浏览器的 localStorage 中，不会同步到其他设备。其他设备没有这份配置时，继续使用线上模型。

## Ollama 配置

在个人中心选择“本地 Ollama”，填写：

```text
Base URL: http://127.0.0.1:11434/v1
模型名称: 例如 qwen2.5-vl:7b 或 llava
API Key: 通常留空
```

保存后，聊天输入框会出现模型来源切换。浏览器直接请求 Ollama 的 OpenAI 兼容接口：

```text
POST {Base URL}/chat/completions
```

需要在 Ollama 侧允许网页来源（`OLLAMA_ORIGINS`）。如果网页通过 HTTPS 访问，浏览器可能限制从 HTTPS 页面请求 HTTP 的本地地址；此时应使用 HTTPS 入口，或在本机开发环境中使用 HTTP 页面。

## 图片识别

网页 Agent 和小伴支持上传、粘贴图片，并将图片以 `image_url` 多模态消息发送给当前选择的模型。Ollama 必须使用支持视觉的模型，例如 `llava`、`qwen2.5-vl`；普通文本模型不能识别图片。

图片先上传到站内 `/uploads/images/`，再交给模型处理，并随消息保存到聊天记录。单条消息最多处理 4 张图片，每张图片大小受上传接口限制。

## 功能差异

- 本地 Ollama：浏览器直连本机，不消耗平台聊天额度；不能使用服务端联网搜索。
- 线上模型：由服务端调用平台默认模型或账号配置的在线 API，可以使用本轮联网搜索。
- 图片生成：继续使用账号配置的图片生成模型；切到本地 Ollama 后不能进入图片生成模式。

## 常见故障

| 现象 | 检查项 |
| --- | --- |
| 无法连接 Ollama | Base URL、Ollama 是否运行、模型名称是否已下载 |
| CORS 错误 | 设置 `OLLAMA_ORIGINS`，并确认网页协议与本地接口访问规则一致 |
| 图片无法识别 | 当前 Ollama 模型是否为视觉模型 |
| 另一台设备没有本地选项 | 本地配置按浏览器保存，不会跨设备同步 |
